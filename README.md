# Holant-X-Dichotomy

This repository contains the exact finite-verification package accompanying *A Dichotomy for Complex Boolean Holant with Binary Disequality* by Chenghua Liu and Boning Meng; see [`certificates/README.md`](certificates/README.md) for requirements, usage, and the manuscript-to-verifier map. The verification code was written by OpenAI Codex and reviewed by the authors.
